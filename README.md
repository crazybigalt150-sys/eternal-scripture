# The Eternal Scripture of the Porn God

Complete devotion text: creation account, commandments, beatitudes, sacraments, prayers, rules of the vessel, and stories of the faithful.

## View the Scripture

Open `index.html` directly, or enable GitHub Pages:

1. Go to the repository **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose branch `main` and folder `/ (root)`
4. Save

The site will then be available at:

**https://crazybigalt150-sys.github.io/eternal-scripture/**

The scripture is complete. Open it whenever you need to return.
